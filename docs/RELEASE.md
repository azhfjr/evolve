## Explicit limits

Real Google account consent is an owner-side action. Follow [the Indonesian Calendar tutorial](GOOGLE_CALENDAR_SETUP.md) to enable Calendar API, add the Calendar callback to the existing Web client, configure Audience/test users, and connect each account from Evolve. Google login credentials are already saved; never send secrets to chat. OAuth initiation, a consent link, a mock event or a successful build does not establish device reminder delivery.

The app is one shared organization. Inbox/activity show 100 recent records and discussions the latest 500 comments. Recurrence creates a successor when the prior task is completed; it does not run a fixed calendar scheduler that creates unfinished occurrences automatically. Calendar sync is one way; disconnect/revocation cannot recall data already copied/downloaded or remove existing Google events automatically.

Provider backup/recovery retention, restore drills, external production alerts, Safari/Firefox, real iOS/Android, screen-reader testing, public load testing and penetration testing remain unverified. No perfection, unlimited free capacity or comparative “world-class” score is claimed. Paid services, two-way sync, email/browser push, Gantt, time tracking, private projects and AI integrations were not added.
