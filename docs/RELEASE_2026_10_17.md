# Production release — task attachments and multi-item Cost

17 October 2026, 16:24 UTC+7. Owner approval explicitly covered deployment to `evolve-rensist.vercel.app` and migrations 0008–0010. This release supersedes the preview-only status in earlier audit documents.

## Released behavior

- Private attachments during task creation, with upload/retry/remove, saved draft references and transactional linking when the task is created.
- Several named project Cost items, each using IDR or USD and an Amount, with exact automatic totals kept separate by currency. Recorded expenses remain separate from planned Cost and aggregate the full ledger.
- Proportional Activity/Settings layouts, the workspace task editor, shared-label Connection map/list and the earlier UI refinements reviewed in PR #4.

## Verification limits and recovery

Full Google consent, upload to production Blob and authenticated Cost/task write-readback were not repeated with the owner's Google session. Production health and access checks do not establish those user journeys by themselves. Safari/Firefox, physical devices, load tests, device reminder delivery and backup restoration remain unverified in this release.

Do not point the domain at an older build that lacks draft-owner guards and per-currency ledger handling. Keep the additive schema and roll forward, or prepare a compatible recovery build preserving those guards and all Cost data. `EVOLVE_DISABLE_TASK_DRAFT_UPLOADS=1` can pause new pre-creation uploads while keeping saved task files available. Reuse the secure production environment; do not copy customer credentials into previews. Future deployments containing migrations must run the checked migration runner before serving the new app; a Git push alone does not deploy this unlinked Vercel project.
